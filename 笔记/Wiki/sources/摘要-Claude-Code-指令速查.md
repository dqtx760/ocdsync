## 核心摘要
Claude Code 全量指令速查手册。涵盖上下文管理（/context、/compact、/clear）、代码回退恢复（Ctrl+_、/rewind、/branch、/resume）、额度与模型调控（/cost、/usage、/effort、/model）、隐藏实用指令（/btw、/diff、/simplify）、权限管理（/permissions、Shift+Tab）以及全套快捷键。同时提供了四种实战组合用法。

## 关键数据
- 上下文管理：/context、/compact、/clear
- 代码回退：/rewind、/branch、/resume
- 额度调控：/cost、/usage、/effort、/model
- 快捷键：Ctrl+J 换行、Ctrl+R 搜历史、双击 Esc 回退
