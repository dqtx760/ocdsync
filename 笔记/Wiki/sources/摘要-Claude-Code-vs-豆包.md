## 核心摘要
Claude Code 与普通 AI（如豆包、通义千问）的核心差异对比。Claude Code 定位为 AI 原生工作环境/数字同事，行动优先，可直接改代码、操作文件、调用 API；普通 AI 为对话问答工具，只提供思路建议。Claude Code 拥有百款内置工具+技能库+MCP 协议、子智能体并行处理、跨会话持久记忆、深度 Git 集成等关键能力。

## 关键数据
- 工具生态：百款内置工具 + 技能库 + MCP 协议
- 协作模式：你定方向，AI 全权执行
- 普通 AI 角色：顾问（只出主意）
- Claude Code 角色：合伙人（出谋划策+直接干活）
