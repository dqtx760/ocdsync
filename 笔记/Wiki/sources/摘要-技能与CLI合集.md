## 核心摘要
Claude Code 生态中的 Skill 和 CLI 工具合集。Skill 涵盖内容创作全链路（选题生成、叙事写作、抖音脚本、多平台分发、PPT 演示、封面图生成、AI 降味审校等），CLI 连接器覆盖即刻、X、飞书等社交与办公平台。同时包含知识库三件套（/ingest、/query、/lint）以及 MCP 工具汇总。

## 关键数据
- 核心 Skill：khazix-writer、x-post、huashu-slides、humanizer 等
- CLI 连接器：jike-web-cli、twitter-cli、lark-cli
