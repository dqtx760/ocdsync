## 核心摘要
从 GitHub 向 Claude Code 安装第三方 Skill 的方法。展示了 skill-creator（创建技能）、find-skills（搜索技能）、aihot（AI 热点查询）三个示例 Skill 的安装流程。用户只需发送"帮我安装"指令，Claude Code 即可自动完成下载和配置。

## 关键数据
- skill-creator：创建自定义 Skill
- find-skills：搜索匹配需求的 Skill
- aihot：查询 AI 相关热点
