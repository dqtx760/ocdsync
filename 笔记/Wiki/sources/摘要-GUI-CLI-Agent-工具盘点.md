## 核心摘要
AI 编程工具全生态分类盘点：GUI IDE（Cursor、Windsurf、Trae 等）、传统 IDE+AI 插件（VS Code+Copilot、IntelliJ+JetBrains AI）、纯 CLI 命令行 AI Agent（海外：Claude Code、Codex CLI、Gemini CLI；国产：Qwen Code、CodeBuddy、Kimi CLI）、桥梁型 CLI（社交/办公/MCP 协议/通用工具）。提供了工具选型总结。

## 关键数据
- GUI IDE 第一梯队：Cursor、Trae、Windsurf
- CLI Agent 第一梯队：Claude Code、Qwen Code、Aider
- 企业团队：VS Code+Copilot、IntelliJ+JetBrains AI
