## 核心摘要
Claude Code 全量命令和快捷键汇总。启动命令（claude --dangerously-skip-permissions、claude -v、claude update）、常用命令（/tools、/skills、/context、/model、/loop、/remote-control、/doctor、/memory 等）以及完整的快捷键列表。包含了从上下文管理到远程控制的全方位操作指令。

- 远程控制：`/remote-control`（/rc 简写）
- 环境检测：`/doctor`
- 持久记忆：`/memory`
