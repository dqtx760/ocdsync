## 核心摘要
Claude Code 的 API Key 配置方案汇总。推荐使用 DeepSeek、Kimi K2 等高性价比平替模型代替 Claude 官方付费订阅——成本不到官方十分之一。列出了 DeepSeek、Kimi、智谱、火山引擎、MiniMax、OpenRouter、小米 MiMo 等十余家 API 供应商及其配置方式。同时提供了免费 Token 计划资源汇总，以及 `~/.claude/settings.json` 的一键创建和配置模板。

## 关键数据
- 推荐模型：DeepSeek V4-Flash、Kimi K2.6
- 顶级模型：Claude Opus 4.7
- 配置路径：`~/.claude/settings.json`
