# MCP 协议

Model Context Protocol（MCP）是一种 AI 工具互连开放协议。让 Claude Code 能够无缝对接飞书/钉钉文档、数据库、第三方 API、本地工具链。

## 应用场景
- 飞书/钉钉文档对接
- 数据库查询与操作
- 第三方 API 调用
- 本地工具链扩展
- 抖音 MCP 服务端
