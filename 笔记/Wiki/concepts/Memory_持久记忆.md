# Memory 持久记忆

Claude Code 的跨会话记忆系统。自动记忆用户偏好、项目上下文、历史决策，跨会话保持一致性。

## 能力
- 实体关系图谱：记录人、工具、概念之间的关联
- 观察记录：保存行为模式和偏好
- 反馈学习：从用户反馈中持续优化

## 优势
- 越用越懂你，无需每次重复背景介绍
- 对话质量指数级提升
- 支持跨会话延续
