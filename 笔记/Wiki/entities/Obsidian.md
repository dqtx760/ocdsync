# Obsidian

Obsidian 是一款基于 Markdown 的知识管理和笔记软件。在本知识库中作为笔记的 IDE/编辑器使用，与 Claude Code 配合形成"Obsidian 是 IDE，LLM 是程序员"的工作流。

## 关联插件
- Claudian（Claude 对话插件）
- BRAT（插件管理）
- Custom Attachment Location
