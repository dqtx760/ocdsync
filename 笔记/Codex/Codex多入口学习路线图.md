# Codex 多入口学习路线图

> 来源：CodexGuide - 学习路线 (https://codexguide.ai/guide/00-overview.html)

Codex 可以在多个入口中出现，包括 CLI、桌面 App、Web / Cloud / ChatGPT、IDE 和集成生态。关键是先理解每个入口适合承载的任务节奏。

---

## 四阶段路线

1. **入门**：跑通一个低风险任务。
2. **进阶**：形成稳定任务方法。
3. **工程化**：进入真实项目流程。
4. **团队化**：沉淀规则和案例。

---

## 新手推荐路径（从 App 开始）

1. 下载安装 Codex 桌面 App，完成登录。
2. 按需订阅 ChatGPT Plus，解锁完整功能。
3. 阅读了解 Codex 基本组成，认识界面结构。
4. 了解手机端如何跟进桌面任务，避免把它误解成远程桌面。
5. 按需了解连接第三方 API 的风险和基本方式；不需要第三方 API 的新手可以跳过。
6. 跟着用 Codex 完成第一个任务，走完一次完整操作闭环。

---

## 开发者推荐路径（从 CLI 开始）

1. 阅读入口地图。
2. 安装 CLI，完成一次登录和版本检查。
3. 用"只读仓库总结"任务确认 Codex 能理解项目。
4. 执行一个低风险修改，例如修文档、补测试或修复单个失败用例。
5. 建立第一个 AGENTS.md，写入项目命令和禁止事项。
6. 阅读配置与扩展，准备 config.toml、Skills 和安全边界。
7. 把成功任务整理成案例，放进团队知识库。

---

## 各入口适合做什么

- **CLI**：贴近终端和本地仓库，适合快速修改、运行命令、排障和验证。
- **桌面 App**：适合本地多任务、Skills、Automations、子代理和插件化工作流。
- **Web / Cloud / ChatGPT**：适合连接仓库、分派长任务、并行处理、生成 PR 或回答代码问题。
- **IDE**：适合贴近编辑器上下文的解释、修改、审查和局部任务。
- **集成生态**：GitHub、Slack、Linear、MCP 等入口让 Codex 接入团队协作链路。

---

## 非开发者也可以怎么用

Codex 的核心能力是"理解一组文件、执行有边界的任务、产出可复核结果"。这也让它适合：

- 阅读陌生代码库，输出学习路线。
- 整理项目文档、README、迁移说明和发布说明。
- 审阅配置、依赖、脚本和 CI 失败原因。
- 把重复流程沉淀成模板、Skill 或自动化提醒。
- 辅助产品、运营、技术写作和团队知识管理。
