# Codex 的 Goal 指令如何用

---

## 什么是 Goal

Goal 是 Codex CLI 和桌面 App 中的一个斜杠命令（/goal），用来为当前对话设置一个明确的目标。

它本质上是一个「任务追踪器」——你告诉 Codex 你想达成什么，Codex 会在完成时标记目标为 complete，并汇报 token 使用量和耗时。

---

## 如何使用

### 设置目标

在对话输入框中输入：

```
/goal 把这个项目的 README 翻译成中文
```

或者直接在对话中说：

```
请创建一个 goal：重构认证模块
```

### 查看当前目标

```
/goal
```

不带参数时会显示当前目标的状态、token 预算和使用情况。

### 目标完成

当任务完成后，Codex 会自动将目标标记为 complete，并报告：
- 使用了多少 token
- 花了多少时间

---

## 适用场景

1. **长任务追踪**：当一个任务需要多轮对话才能完成时，Goal 帮你追踪进度。
2. **Token 预算管理**：可以给 Goal 设置 token 上限，防止消耗过多。
3. **任务复盘**：完成后可以看到 token 用量和耗时，帮助评估效率。

---

## 常见用法示例

```
/goal 修复登录模块的所有单元测试
/goal 编写项目的 AGENTS.md
/goal 将 10 个 API 端点添加错误处理
/goal 分析这个仓库的架构并输出学习路线
```

---

## 小结

- /goal 用来设置和追踪当前对话的任务目标。
- 支持设置 token 预算，完成后自动汇报用量。
- 适合长任务、复杂任务的进度管理和复盘。
