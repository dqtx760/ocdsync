# Codex 学习路径与练习计划

本文档用于规划 Codex 学习目标、练习任务和持续复盘，帮助你从配置使用逐步进阶到高效开发。

---

## 学习目标

- 能独立完成 Codex 环境配置与故障排查。
- 掌握常用工作流：需求拆解、代码生成、测试、调试、重构。
- 学会设计高质量 Prompt，提高 Codex 输出的一致性和可维护性。
- 理解项目约束、安全与成本控制，形成可复用开发习惯。

---

## 阶段划分

### 阶段一：基础配置与上手

- 复习现有笔记中的 API 接入与本地代理配置。
- 完成一次完整的启动、验证、失败排查、修复闭环。
- 记录你常用的环境变量、配置路径、命令别名。

### 阶段二：日常开发流程

- 练习将需求拆解为 3~5 步任务，再交给 Codex 执行。
- 学会先写伪代码或接口定义，再让 Codex 填充实现。
- 每次生成后做代码审查，重点检查边界条件、错误处理、命名。

### 阶段三：Prompt 与上下文设计

- 建立常用 Prompt 模板库（调试、重构、测试、文档）。
- 练习在 Prompt 中提供约束：代码风格、返回格式、禁止事项。
- 使用上下文文件、目录说明和历史记录，提高一致性。

### 阶段四：工程化与质量控制

- 让 Codex 生成测试，并自己补充关键边界测试。
- 用 Lint、Type Check、单测形成自动验证流程。
- 学习对生成代码做增量修改，而不是每次重写。

### 阶段五：复盘与沉淀

- 每周整理成功案例、常见错误和修复方法。
- 将高频 Prompt 和工作流固化为个人模板。
- 持续更新笔记，形成自己的 Codex 使用手册。

---

## 推荐练习任务

1. 给定一个小型需求，先自己写步骤，再让 Codex 实现，对比差异。
2. 使用 Codex 生成单元测试，然后故意修改逻辑检查测试是否捕获错误。
3. 让 Codex 重构一段旧代码，要求保持接口不变并补充注释。
4. 模拟报错场景，请 Codex 给出排查步骤和修复建议。
5. 用 Codex 起草 API 文档，再人工修正描述和示例。

## 持续学习建议

- 每次只聚焦一个主题，避免一次性学习太多功能。
- 先慢后快，先保证质量，再提高生成速度。
- 养成“先结构后细节”的开发习惯。
- 把 Codex 当搭档，而不是全自动答案机。
